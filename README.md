# Richa & Rahul — Royal Wedding Invitation Website 💍✨

An elegant, interactive wedding invitation website featuring:
- Full-screen interactive video intro
- Romantic background music
- Scratch-to-reveal wedding date card
- Add to Calendar integration (Google, Apple iCal, Outlook, Yahoo)
- Venue maps and navigation
- Guest RSVP form with persistence
- Floating royal hearts animation

## GitHub Pages Deployment
This website is ready to be hosted directly with **GitHub Pages**:
1. In your GitHub repository, navigate to **Settings** > **Pages**.
2. Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
3. Under **Branch**, select `main` and folder `/ (root)`.
4. Click **Save**. Your website will be live at `https://<username>.github.io/<repo-name>/`.
